# webgames

A collection of browser-based games built for local network play.

## tanks

A multiplayer tank battle game originally hacked together on a train at **[Hobocon](https://www.hobocon.com/)**. Because sometimes the best gaming session is the one rolling down the tracks at 80mph.

Play it live at **[tanks.adamschaal.com](https://tanks.adamschaal.com)**, or run it locally on a shared network — no internet required, just a hotspot and a browser.

See [tanks/README.md](tanks/README.md) for setup and running instructions.
