# webgames

A collection of browser-based games built for local network play.

## tank

A multiplayer tank battle game built for LAN play. Originally created at **Hobocon** — hacked together on a train, for play on the train. Because sometimes the best gaming session is the one rolling down the tracks at 70mph.

Players connect over the local network and battle it out in real-time. No internet required — just a shared WiFi or hotspot and a browser.

### Running tank

```bash
cd tank
npm install
node server.js
```

Then have everyone on the same network open their browser to your machine's IP on the configured port.
